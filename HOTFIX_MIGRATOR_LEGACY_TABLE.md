# Исправление ошибки `столбец "filename" не существует`

Причина: в действующей базе уже есть старая таблица `public.schema_migrations`,
созданная прежним механизмом миграций. В ней нет колонок `filename`, `checksum`
и других полей нового журнала.

Исправленный `db/migrator.py`:

1. Проверяет фактические колонки таблицы, а не полагается на
   `CREATE TABLE IF NOT EXISTS`.
2. Несовместимую старую таблицу переименовывает в
   `schema_migrations_legacy_YYYYMMDD_HHMMSS`.
3. Создаёт новый журнал `public.schema_migrations`.
4. Применяет миграции `001...005` поверх существующей базы. SQL-файлы сделаны
   повторно применимыми и не удаляют пользовательские данные.

## Установка

1. Остановить все копии бота и `find_discussion_id.py`.
2. Скопировать содержимое патча поверх проекта с заменой файлов.
3. Запустить из корня проекта:

```powershell
python -m db.migrator
```

4. После успешного применения миграций запустить:

```powershell
python main.py
```

Старую таблицу журнала удалять вручную не нужно. Она остаётся в базе как архив.
