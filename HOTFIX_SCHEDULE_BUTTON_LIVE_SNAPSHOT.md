# Hotfix: актуальный снимок кнопки «Расписание»

Исправлена отдельная ветка административной кнопки `📅 Расписание`.

## Причина

Запрос подробного расписания использовал собственный набор статусов:

- включал `finished`, хотя завершённый лот больше не является частью текущего расписания;
- не включал `approved` и `publishing`, хотя такие лоты уже занимают слот;
- обычный `LEFT JOIN cards` мог размножать один аукцион при дублирующихся карточках;
- в сообщении нельзя было понять, когда именно данные были перечитаны.

## Исправление

- живые статусы: `approved`, `scheduled`, `publishing`, `active`;
- `finished` исключён из кнопки текущего расписания;
- карта выбирается через `LEFT JOIN LATERAL ... LIMIT 1`, один аукцион выводится один раз;
- занятость и конфликты используют тот же набор живых статусов;
- callback подтверждается до тяжёлой выборки;
- в заголовке указывается время свежего чтения БД в МСК;
- времена отображаются через единый Moscow-time helper.
