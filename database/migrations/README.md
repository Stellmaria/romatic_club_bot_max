# Архив старой истории миграций

SQL-файлы в этом каталоге сохранены только для исторического аудита старой схемы.
Они **не упаковываются**, **не исполняются** и не являются местом для новых
изменений базы данных.

Единственный runtime-runner:

- `db/migrator.py`
- `db/migrations/NNN_description.sql`

Новую миграцию следует добавлять только в `db/migrations` с номером больше
последнего существующего. Совместимый модуль `db/migrations.py` лишь делегирует
вызовы в `db.migrator` и не содержит отдельного механизма применения SQL.
