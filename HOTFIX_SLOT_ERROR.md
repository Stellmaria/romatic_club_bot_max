# Ошибка «Этот слот уже заняли»

Причина: слот публикации имеет шаг 30 минут, но старый триггер сохранял `end_time`
как `start_time + 31 минуту`. Проверка пересечения считала соседний слот занятым.

Исправление включает:

- миграцию `005_fix_auction_slot_duration.sql`;
- хранение окончания как `start_time + 30 минут 59 секунд`;
- проверку коллизии по времени начала получасового слота;
- исключение текущего `auction_id`;
- атомарную проверку при окончательном подтверждении.

Скопируйте файлы патча поверх проекта и перезапустите бота. Ручной запуск SQL не
нужен, если при старте вызывается `db.migrator`.
