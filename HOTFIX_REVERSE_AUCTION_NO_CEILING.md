# Хотфикс обратных аукционов без фиксированного потолка

Изменено поведение аукционов `auction_kind = reverse`:

- после выбора валюты пользователь не выбирает диапазон или стартовую цену;
- в базе для такой заявки сохраняется `start_price = 0` как техническое значение;
- первая ставка может быть любой положительной суммой с правильным шагом валюты;
- каждая следующая ставка должна быть ниже текущей лучшей минимум на один шаг;
- в публикации, заявке и админском отображении не выводится фиктивная верхняя граница;
- предупреждение об обычном пороге проверки победителя для reverse не показывается;
- победителем выбирается минимальная валидная ставка.

Миграция `db/migrations/006_reverse_auction_without_ceiling.sql` обновляет функцию
`public.is_valid_bid` в существующей PostgreSQL-базе.
